7  Biological moderators

  • Show All Code
  • Hide All Code
  • View Source

This section presents single-moderator models for ecological, life-history, and geographic predictors of brood-level mixed paternity. These models evaluate whether mixed-paternity prevalence varies with nest type, migration status, coloniality, clutch size, body mass, and absolute latitude, while retaining the same multilevel phylogenetic beta-binomial structure used in the overall model.

Model-based prevalence is summarised as the posterior mean on the probability scale, with 95% equal-tailed credible intervals. The inverse-logit transformation is applied to each posterior draw before averaging; all random effects are set to zero.

7.3 Model

This helper function documents the shared model structure used for all single-moderator models. These models are fitted outside this website workflow and saved as .rds files.

The nest-type model uses 0 + nest_type_model, with one logit coefficient per category and no shared population-level intercept. The other models in this chapter retain an intercept. Model-specific reference categories and priors are documented in the overall-model chapter.

Code 
#| eval: false
#| echo: true

fit_single_moderator <- function(formula, data) {
  brm(
    formula = formula,
    data = data,
    family = beta_binomial(link = "logit"),
    data2 = list(phylo_mat = phylo_mat),
    chains = 4,
    cores = 4,
    iter = 10000,
    warmup = 5000,
    control = list(
      adapt_delta = 0.99,
      max_treedepth = 15
    ),
    seed = 123
  )
}

7.4 Nest type architecture

This model tested whether mixed-paternity prevalence differed among nest-type categories. Nest type was derived from BIRDBASE and simplified into four broad nest-architecture categories: cavity, ground, open, and other enclosed nests. Cavity nests included tree cavities and crevices; ground nests included burrows, scrapes, mounds, and nests placed directly on or in the ground; open nests included cups, saucers, platforms, and half-cups; and other enclosed nests included domes, pendant and globular nests, as well as nests built in other birds’ nests.

7.4.4 Post-hoc pairwise contrasts

Pairwise contrasts are posterior means with 95% equal-tailed credible intervals. Each contrast compares the first category with the second. Log-odds differences are calculated within each posterior draw. Odds ratios are summarised after exponentiating each difference, so mean OR is the mean of the transformed draws, not the exponential of the mean log-odds difference.

Code
b <- brms::fixef(model_nest_type, summary = FALSE)
pairs <- combn(colnames(b), 2L, simplify = FALSE)
nest_type_contrasts <- do.call(rbind, lapply(pairs, function(pair) {
  difference <- b[, pair[1L]] - b[, pair[2L]]
  odds_ratio <- exp(difference)
  data.frame(
    contrast = paste(sub("nest_type_model", "", pair, fixed = TRUE), collapse = " - "),
    estimate = mean(difference),
    lower.CrI = unname(quantile(difference, 0.025)),
    upper.CrI = unname(quantile(difference, 0.975)),
    OR = mean(odds_ratio),
    lower.OR = unname(quantile(odds_ratio, 0.025)),
    upper.OR = unname(quantile(odds_ratio, 0.975))
  )
}))

7.5.3 Model estimates

The intercept represents the reference migration category, while the remaining coefficients describe differences relative to that reference category on the logit scale.

The single-moderator model used 619 records and estimated beta = −0.387 (95% equal-tailed CrI −0.704 to −0.066; posterior mean OR = 0.688). The primary multivariable model used 533 records and estimated beta = −0.492 (−0.861 to −0.132; posterior mean OR = 0.622). The direction is consistent, and the adjusted point estimate is more negative. Because both covariate adjustment and sample composition differ, this descriptive comparison does not establish a change in association strength. In both models, OR means are calculated after exponentiating each coefficient draw.

These models evaluate whether mixed-paternity prevalence varies with nest type, migration status, coloniality, clutch size, body mass, and absolute latitude, while retaining the same multilevel phylogenetic beta-binomial structure used in the overall model.
:::

Model-based prevalence is summarised as the posterior mean on the probability scale, with 95% equal-tailed credible intervals. The inverse-logit transformation is applied to each posterior draw before averaging; all random effects are set to zero.

## Model

This helper function documents the shared model structure used for all single-moderator models. These models are fitted outside this website workflow and saved as `.rds` files.

The nest-type model uses 0 + nest_type_model, with one logit coefficient per category and no shared population-level intercept. The other models in this chapter retain an intercept. Model-specific reference categories and priors are documented in the [overall-model chapter](03_overall_model.qmd#model-coding-and-priors).

```{r}

#| eval: false
#| echo: true

fit_single_moderator <- function(formula, data) {
  brm(
    formula = formula,
    data = data,
    family = beta_binomial(link = "logit"),
    data2 = list(phylo_mat = phylo_mat),
    chains = 4,
    cores = 4,
    iter = 10000,
    warmup = 5000,
    control = list(
      adapt_delta = 0.99,
      max_treedepth = 15
    ),
    seed = 123
  )
}
```

## Nest type architecture

This model tested whether mixed-paternity prevalence differed among nest-type categories. Nest type was derived from BIRDBASE and simplified into four broad nest-architecture categories: cavity, ground, open, and other enclosed nests. Cavity nests included tree cavities and crevices; ground nests included burrows, scrapes, mounds, and nests placed directly on or in the ground; open nests included cups, saucers, platforms, and half-cups; and other enclosed nests included domes, pendant and globular nests, as well as nests built in other birds’ nests.

### Post-hoc pairwise contrasts

Pairwise contrasts are posterior means with 95% equal-tailed credible intervals. Each contrast compares the first category with the second. Log-odds differences are calculated within each posterior draw. Odds ratios are summarised after exponentiating each difference, so mean OR is the mean of the transformed draws, not the exponential of the mean log-odds difference.

```{r}
#| echo: true
#| code-fold: true
#| message: false
#| warning: false

b <- brms::fixef(model_nest_type, summary = FALSE)
pairs <- combn(colnames(b), 2L, simplify = FALSE)
nest_type_contrasts <- do.call(rbind, lapply(pairs, function(pair) {
  difference <- b[, pair[1L]] - b[, pair[2L]]
  odds_ratio <- exp(difference)
  data.frame(
    contrast = paste(sub("nest_type_model", "", pair, fixed = TRUE), collapse = " - "),
    estimate = mean(difference),
    lower.CrI = unname(quantile(difference, 0.025)),
    upper.CrI = unname(quantile(difference, 0.975)),
    OR = mean(odds_ratio),
    lower.OR = unname(quantile(odds_ratio, 0.025)),
    upper.OR = unname(quantile(odds_ratio, 0.975))
  )
}))
knitr::kable(nest_type_contrasts, digits = 3,
  caption = "Posterior means and 95% equal-tailed intervals: log-odds contrasts and odds ratios.")
```

### Model estimates

The intercept represents the reference migration category, while the remaining coefficients describe differences relative to that reference category on the logit scale.

The single-moderator model used 619 records and estimated beta = −0.387 (95% equal-tailed CrI −0.704 to −0.066; posterior mean OR = 0.688). The primary multivariable model used 533 records and estimated beta = −0.492 (−0.861 to −0.132; posterior mean OR = 0.622). The direction is consistent, and the adjusted point estimate is more negative. Because both covariate adjustment and sample composition differ, this descriptive comparison does not establish a change in association strength. In both models, OR means are calculated after exponentiating each coefficient draw.

There was no clear directional association between log10 body mass and mixed-paternity prevalence: posterior mean beta = −0.008 (95% equal-tailed CrI −0.303 to 0.289), and posterior mean OR = 1.004 (0.739 to 1.335). The means are calculated on their respective scales: exp(mean(beta_draws)) = 0.992, whereas mean(exp(beta_draws)) = 1.004. Their positions on opposite sides of the null values arise from nonlinear averaging (Jensen’s inequality). In 52.3% of draws, both beta < 0 and OR < 1; neither direction was clearly supported.

## Heterogeneity summary

```{r}
#| echo: false
#| message: false
#| warning: false
variance_table <- readr::read_csv("tables/variance_audit/group_level_variances.csv", show_col_types = FALSE) |>
  dplyr::filter(Model %in% c("Overall model", "Nest type", "Migration", "Coloniality", "Clutch size", "Body mass", "Absolute latitude"))
knitr::kable(variance_table, digits = 3)
```

Group-level entries are posterior mean variances on the logit scale, calculated by squaring each posterior SD draw before averaging. Phi is the beta-binomial precision parameter. Models use different complete-case samples; these tables do not measure heterogeneity explained by individual moderators.
