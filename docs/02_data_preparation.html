This table summarises the curated input dataset and the phylogenetic tree.

The input CSV is the curated database: 676 records grouped under 607 distinct study identifiers (Study_ID), covering 393 species. The manuscript documents its derivation from 702 assembled records after removal of 26 overlapping records. Excluding 57 records without the required outcome or denominator leaves 619 records; exclusion of the two ambiguous records then leaves 617 analytical records, 553 study identifiers and 373 species. Thus, 607 and 553 refer to different dataset stages. The supplement lists 608 distinct source-publication entries for the broader curated database; bibliographic entries and analytical study identifiers are different counting units.

The updated literature search has a separate counting sequence: 2,288 identified bibliographic records minus 623 duplicates gives 1,665 screened records; excluding 1,476 at title/abstract screening leaves 189 reports for full-text assessment. Of these, 46 were excluded and 143 reports were included. Reports are source documents, not unique analytical study identifiers or database rows. See the updated search flow diagram.

3.3 Prepare data

3.3.1 Population identifier

Population identity was defined using study identity and rounded geographic coordinates, with latitude and longitude rounded to two decimal places prior to constructing the population identifier.


mixed_pat <- mixed_pat_raw %>%

3.3.2 Study and species formatting

The following step formats the main grouping variables used in the models and calculates the total number of broods by combining mixed- and non-mixed-brood counts.


mixed_pat <- mixed_pat %>%
  mutate(
    Study_ID = as.factor(Study_ID),
    species_phylo_brms = as.factor(Clements_name),

3.3.3 Phylogeny preparation

Species names were harmonised between the mixed-paternity dataset and the phylogenetic tree prior to pruning the tree and generating the phylogenetic covariance matrix used in the Bayesian models.

3.4.2 Common scaling of continuous moderators

The centring and scaling constants are calculated once from the 619-record overall analytical dataset, before moderator-specific complete-case filtering. The same constants are then reused in every single-moderator and multivariable analysis.


data_overall_study <- data_overall_study %>%
  mutate(
    log_body_mass = replace(
      body_mass,
      !is.na(body_mass) & body_mass <= 0,
      NA_real_
    ),
    log_body_mass = log10(log_body_mass)
  )

scaling_constants <- data_overall_study %>%
  summarise(
    study_duration_mean = mean(study_duration, na.rm = TRUE),
    study_duration_sd = sd(study_duration, na.rm = TRUE),
    CS_max_mean = mean(CS_max, na.rm = TRUE),
    CS_max_sd = sd(CS_max, na.rm = TRUE),
    log_body_mass_mean = mean(log_body_mass, na.rm = TRUE),
    log_body_mass_sd = sd(log_body_mass, na.rm = TRUE),
    abs_lat_mean = mean(abs_lat, na.rm = TRUE),
    abs_lat_sd = sd(abs_lat, na.rm = TRUE)
  )

data_overall_study <- data_overall_study %>%
  mutate(
    study_duration_sc =
      (study_duration - scaling_constants$study_duration_mean) /
      scaling_constants$study_duration_sd,
    CS_max_sc =
      (CS_max - scaling_constants$CS_max_mean) /
      scaling_constants$CS_max_sd,
    log_body_mass_sc =
      (log_body_mass - scaling_constants$log_body_mass_mean) /
      scaling_constants$log_body_mass_sd,
    abs_lat_sc =
      (abs_lat - scaling_constants$abs_lat_mean) /
      scaling_constants$abs_lat_sd
  )

scaling_table <- tibble::tribble(
  ~Predictor, ~N, ~Mean, ~SD, ~Unit,
  "Study duration", sum(!is.na(data_overall_study$study_duration)),
    scaling_constants$study_duration_mean, scaling_constants$study_duration_sd, "years",
  "Maximum clutch size", sum(!is.na(data_overall_study$CS_max)),
    scaling_constants$CS_max_mean, scaling_constants$CS_max_sd, "eggs",
  "Body mass", sum(!is.na(data_overall_study$log_body_mass)),
    scaling_constants$log_body_mass_mean, scaling_constants$log_body_mass_sd, "log10(g)",
  "Absolute latitude", sum(!is.na(data_overall_study$abs_lat)),
    scaling_constants$abs_lat_mean, scaling_constants$abs_lat_sd, "degrees"
) %>%
  mutate(across(c(Mean, SD), ~ round(.x, 3)))

3.5 Relationship among candidate random-effects grouping factors

Before fitting the models, we evaluated the degree of overlap and nesting among candidate random-effects grouping factors, including species identity, study identity, and the pragmatic population identifier.


count_one_match <- function(data, group_var, match_var, comparison_label) {
  data %>%
    distinct({{ group_var }}, {{ match_var }}) %>%
    count({{ group_var }}, name = "n_matches") %>%
    summarise(
      Comparison = comparison_label,
      Groups_with_only_one_match = sum(n_matches == 1),
      Total_groups = n(),
      Percent_only_one_match = round(mean(n_matches == 1) * 100, 1),
      .groups = "drop"
    )
}

random_effect_structure <- bind_rows(
  count_one_match(data_overall_study, species_nonphylo, population_id, "Populations per species"),
  count_one_match(data_overall_study, population_id, species_nonphylo, "Species per population"),
  count_one_match(data_overall_study, Study_ID, population_id, "Populations per reference"),
  count_one_match(data_overall_study, population_id, Study_ID, "References per population"),
  count_one_match(data_overall_study, species_nonphylo, Study_ID, "References per species"),
  count_one_match(data_overall_study, Study_ID, species_nonphylo, "Species per reference")
)

3.7 Overlap between nest-box use and nest type (Table S7)

This descriptive table uses the overall analytical dataset prepared in this chapter: 575 of its 619 records have both nest-box use and nest type available. The remaining 44 records have missing information for one or both variables. Counts refer to records, not unique species or publications. This is a different sample from the 533 complete cases used for the primary multivariable model and Tables S5 and S8.

Of the 165 nest-box records, 119 (72.1%) were classified as cavity nesting. Nest type is included in the primary multivariable model, whereas nest-box use was evaluated in a separate single-moderator model. The table describes overlap between these candidate variables; it does not estimate their independent associations with mixed paternity.


summarise_nest_box_overlap <- function(data_overall_study) {
  required <- c("nest_box_model", "nest_type_model")
  stopifnot(nrow(data_overall_study) == 619L,
            all(required %in% names(data_overall_study)))
  complete <- complete.cases(data_overall_study[required])
  dat <- data_overall_study[complete, required, drop = FALSE]
  stopifnot(nrow(dat) == 575L, sum(!complete) == 44L)
  box_levels <- c("no", "yes")
  nest_levels <- c("cavity", "ground", "open", "other_enclosed")
  stopifnot(all(as.character(dat$nest_box_model) %in% box_levels),
            all(as.character(dat$nest_type_model) %in% nest_levels))
  counts <- table(
    factor(dat$nest_box_model, levels = box_levels),
    factor(dat$nest_type_model, levels = nest_levels)
  )
  counts <- rbind(counts, Total = colSums(counts))
  counts <- cbind(counts, Total = rowSums(counts))
  stopifnot(counts["Total", "Total"] == 575L)
  data.frame(
    `Nest-box use` = c("No", "Yes", "Total"),
    Cavity = as.integer(counts[, "cavity"]),
    Ground = as.integer(counts[, "ground"]),
    Open = as.integer(counts[, "open"]),
    `Other enclosed` = as.integer(counts[, "other_enclosed"]),
    Total = as.integer(counts[, "Total"]),
    check.names = FALSE
  )
}

overlap_table <- summarise_nest_box_overlap(data_overall_study)
dir.create("tables", showWarnings = FALSE, recursive = TRUE)
write.csv(overlap_table, "tables/nest_box_nest_type_overlap.csv", row.names = FALSE)
knitr::kable(overlap_table, caption = "Table S7. Nest-box use by nest type in 575 complete records from the 619-record overall analytical dataset; 44 records with missing information are excluded.")

3.8 Two-record analytical exclusion (5 November 2026)

All results on this page use the models after exclusion of the two records for the common ostrich (6/6) and Nelson’s sparrow (8/8), whose exact counts could not be verified as broods with at least two genetic sires. Other records were retained, including the saltmarsh-sparrow record from the same Walsh study. Updated 5 November 2026.

The curated input CSV remains unchanged so that exclusions remain auditable. Apply this rule to each prepared model dataset before fitting; retain original scaling constants and priors.

exclude <- (d$Study_ID == "100Kimwele2002" & d$n_mixed_broods == 6 & d$n_total_broods == 6) |
           (d$Study_ID == "670Walsh2018" & d$n_mixed_broods == 8 & d$n_total_broods == 8)
d <- d[!replace(exclude, is.na(exclude), FALSE), , drop = FALSE]

count_one_match <- function(data, group_var, match_var, comparison_label) {
  data %>%
    distinct({{ group_var }}, {{ match_var }}) %>%
    count({{ group_var }}, name = "n_matches") %>%
    summarise(
      Comparison = comparison_label,
      Groups_with_only_one_match = sum(n_matches == 1),
      Total_groups = n(),
      Percent_only_one_match = round(mean(n_matches == 1) * 100, 1),
      .groups = "drop"
    )
}

## Overlap between nest-box use and nest type (Table S7) {#nest-box-nest-type-overlap}

This descriptive table uses the overall analytical dataset prepared in this chapter: 575 of its 619 records have both nest-box use and nest type available. The remaining 44 records have missing information for one or both variables. Counts refer to records, not unique species or publications. This is a different sample from the 533 complete cases used for the primary multivariable model and Tables S5 and S8.

Of the 165 nest-box records, 119 (72.1%) were classified as cavity nesting. Nest type is included in the primary multivariable model, whereas nest-box use was evaluated in a separate single-moderator model. The table describes overlap between these candidate variables; it does not estimate their independent associations with mixed paternity.

```r

summarise_nest_box_overlap <- function(data_overall_study) {
  required <- c("nest_box_model", "nest_type_model")
  stopifnot(nrow(data_overall_study) == 619L,
            all(required %in% names(data_overall_study)))
  complete <- complete.cases(data_overall_study[required])
  dat <- data_overall_study[complete, required, drop = FALSE]
  stopifnot(nrow(dat) == 575L, sum(!complete) == 44L)
  box_levels <- c("no", "yes")
  nest_levels <- c("cavity", "ground", "open", "other_enclosed")
  stopifnot(all(as.character(dat$nest_box_model) %in% box_levels),
            all(as.character(dat$nest_type_model) %in% nest_levels))
  counts <- table(
    factor(dat$nest_box_model, levels = box_levels),
    factor(dat$nest_type_model, levels = nest_levels)
  )
  counts <- rbind(counts, Total = colSums(counts))
  counts <- cbind(counts, Total = rowSums(counts))
  stopifnot(counts["Total", "Total"] == 575L)
  data.frame(
    `Nest-box use` = c("No", "Yes", "Total"),
    Cavity = as.integer(counts[, "cavity"]),
    Ground = as.integer(counts[, "ground"]),
    Open = as.integer(counts[, "open"]),
    `Other enclosed` = as.integer(counts[, "other_enclosed"]),
    Total = as.integer(counts[, "Total"]),
    check.names = FALSE
  )
}

overlap_table <- summarise_nest_box_overlap(data_overall_study)
dir.create("tables", showWarnings = FALSE, recursive = TRUE)
write.csv(overlap_table, "tables/nest_box_nest_type_overlap.csv", row.names = FALSE)
knitr::kable(overlap_table, caption = "Table S7. Nest-box use by nest type in 575 complete records from the 619-record overall analytical dataset; 44 records with missing information are excluded.")
```
