This section presents the intercept-only beta-binomial phylogenetic model used to estimate the population-level intercept and quantify heterogeneity in mixed-paternity prevalence across birds. The model accounts for study identifier, non-phylogenetic species-level variation, and phylogenetically structured species-level variation.

4.4 Modelling framework

Because brood-level paternity data are expected to exhibit substantial extra-binomial heterogeneity across references, populations, and species, we modelled mixed-paternity prevalence using beta-binomial generalised linear mixed-effects models with a logit link:

\[y_i \sim \mathrm{BetaBinomial}(n_i, \mu_i, \phi)\]

where \(y_i\) is the number of broods with mixed paternity, \(n_i\) is the total number of broods genotyped, \(\mu_i\) is the expected mixed-paternity prevalence, and the precision parameter \(\phi\) describes extra-binomial variation among study units.

For models with a population-level intercept, the linear predictor was:

\[\mathrm{logit}(\mu_i) = \alpha + \mathbf{X}_i \boldsymbol{\beta} + u_{\mathrm{reference}[i]} + u_{\mathrm{species}[i]} + u_{\mathrm{phylo}[i]}\]

where \(\alpha\) is the intercept, \(\mathbf{X}_i \boldsymbol{\beta}\) represents fixed biological and methodological moderators, and \(u_{\mathrm{reference}}\), \(u_{\mathrm{species}}\), and \(u_{\mathrm{phylo}}\) represent study-identifier-level, non-phylogenetic species-level, and phylogenetically structured random effects, respectively. Study identifier (Study_ID) is an analytical grouping variable, not a bibliographic-publication count; one study identifier can incorporate evidence reported across more than one source.

The single-moderator models for marker type, nest type, BG breeding system, BIRDBASE mating system, and parental care use 0 + category: each fitted category has its own logit coefficient, with no shared population-level intercept or reference category. Pairwise contrasts subtract category coefficients within each posterior draw. The primary multivariable model and binary single-moderator models instead use an intercept and reference-category contrasts. All models retain the three random-intercept terms.

4.5.1 Model

The intercept-only model estimated the population-level intercept while quantifying study-identifier-level, non-phylogenetic species-level, and phylogenetically structured species-level variation. model_overall_study <- brm(
  n_mixed_broods | trials(n_total_broods) ~
    1 +
    (1 | Study_ID) +

4.5.5 Phylogenetic signal

We quantified the phylogenetic signal in between-species variation as the proportion of species-level variance attributable to the phylogenetically structured random effect:

\[ \nu = \frac{\sigma^2_{\mathrm{phylo}}} {\sigma^2_{\mathrm{phylo}} + \sigma^2_{\mathrm{nonphylo}}} \]

where \(\sigma^2_{\mathrm{phylo}}\) is the variance of the phylogenetically structured species-level random effect and \(\sigma^2_{\mathrm{nonphylo}}\) is the variance of the non-phylogenetic species-level random effect.

Matched-sample model without moderators

This additional intercept-only model provides a matched-sample reference for the final multivariable model (Supplementary Table S12). It uses exactly the same 533 observations from 481 study identifiers and 326 species. It is distinct from the overall model above, which uses the full dataset of 619 observations; it is not a replacement estimate of overall mixed-paternity prevalence.

The response is the number of mixed-paternity broods out of the total number of broods, modelled with a beta-binomial distribution and a logit link. The matched model includes an intercept and random intercepts for study identifier, non-phylogenetic species identity, and phylogenetically structured species identity, with no moderators. The data, phylogenetic covariance matrix, grouping structure and corresponding priors are retained from the final multivariable model. Priors are Student-t(3, 0, 2.5) for the intercept and group-level standard deviations (restricted to positive values for standard deviations), and Gamma(0.01, 0.01), in shape-rate notation, for beta-binomial precision.

Model

Code
matched_priors <- c(
  set_prior("student_t(3, 0, 2.5)", class = "Intercept"),
  set_prior("student_t(3, 0, 2.5)", class = "sd"),
  set_prior("gamma(0.01, 0.01)", class = "phi")
)

model_null_matched <- brm(
  n_mixed_broods | trials(n_total_broods) ~ 1 +
    (1 | Study_ID) + (1 | species_nonphylo) +
    (1 | gr(species_phylo_brms, cov = phylo_mat_matched)),
  data = data_null_matched,
  data2 = list(phylo_mat_matched = phylo_mat_matched),
  family = beta_binomial(link = "logit"),
  prior = matched_priors,
  chains = 4, cores = 4, iter = 10000, warmup = 5000,
  seed = 20261015,
  control = list(adapt_delta = 0.99, max_treedepth = 15),
  file = "comment44_variance_20261015/model_null_matched_533",
  file_refit = "on_change"
)

Results

The null model was fitted on Totoro with four chains, 10,000 iterations per chain including 5,000 warmup iterations (20,000 retained draws), seed 20261015, adapt_delta = 0.99 and max_treedepth = 15. Maximum R-hat was 1.003; minimum bulk and tail effective sample sizes were 844 and 1,738, respectively. There were no divergent transitions or maximum-treedepth hits. The existing final multivariable model was not refitted.

The table reports posterior mean variances and equal-tailed 95% credible intervals on the logit scale. Each posterior standard-deviation draw was squared before summarising; the sum was calculated within each model draw. Descriptive reduction (%) = 100 × (1 − posterior mean variance in the multivariable model / posterior mean variance in the matched intercept-only model). Negative reductions indicate an increase.

### Results {#matched-results}

The null model was fitted on Totoro with four chains, 10,000 iterations per chain including 5,000 warmup iterations (20,000 retained draws), seed 20261015, adapt_delta = 0.99 and max_treedepth = 15. Maximum R-hat was 1.003; minimum bulk and tail effective sample sizes were 844 and 1,738, respectively. There were no divergent transitions or maximum-treedepth hits. The existing final multivariable model was not refitted.

The table reports posterior mean variances and equal-tailed 95% credible intervals on the logit scale. Each posterior standard-deviation draw was squared before summarising; the sum was calculated within each model draw. Descriptive reduction (%) = 100 × (1 − posterior mean variance in the multivariable model / posterior mean variance in the matched intercept-only model). Negative reductions indicate an increase.
