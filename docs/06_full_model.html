7  Multivariable moderator model

  • Show All Code
  • Hide All Code
  • View Source

This section documents the multivariable moderator phylogenetic beta-binomial model for mixed-paternity prevalence. Alternative classification schemes capture overlapping but not identical aspects of avian reproductive organisation, so they were evaluated as separate representations rather than included simultaneously in the multivariable moderator model. These alternatives included the breeding-system classification of Brouwer and Griffith (2019), a BIRDBASE-derived mono-/polygamy classification, parental-care classifications based on Cockburn (2006) and Griesser et al. (2017), and cooperative-breeding status from the Co-BreeD database.

The multivariable moderator model uses the Brouwer and Griffith breeding-system classification because it provides the most complete and interpretable representation for the multivariable model. Rare Brouwer and Griffith categories represented by fewer than five observations were excluded during data preparation. Nest type is retained, whereas nest-box use is excluded because it partially overlaps with nest type in biological and sampling information. Cooperative breeding is excluded because it strongly overlaps with the Brouwer and Griffith breeding-system classification.

7.6 Model specification

The model formula is shown below.

Code 
full_brouwer_griffith_formula <- bf(
  n_mixed_broods | trials(n_total_broods) ~
    marker_type_model +
    study_duration_sc +
    breeding_system +
    nest_type_model +
    migration +
    coloniality +
    CS_max_sc +
    log_body_mass_sc +
    abs_lat_sc +
    (1 | Study_ID) +
    (1 | species_nonphylo) +
    (1 | gr(species_phylo_brms, cov = phylo_mat))
)

7.7 Fitting code

Code 
model_full_brouwer_griffith <- brm(
  formula = full_brouwer_griffith_formula,
  family = beta_binomial(link = "logit"),
  data = data_full_brouwer_griffith,
  data2 = list(phylo_mat = phylo_mat),
  chains = 4,
  cores = 4,
  iter = 10000,
  warmup = 5000,
  control = list(
    adapt_delta = 0.99,
    max_treedepth = 15
  ),
  seed = 123
)

saveRDS(model_full_brouwer_griffith, "models/model_full_BG.rds")

## Model diagnostics

```{r}
#| label: full-model-diagnostics
#| echo: false
#| message: false
#| warning: false

diagnostics_file <- first_existing(c(
  "models/diagnostics_model_full_BG.csv",
  "models/diagnostics_model_full_brouwer_griffith.csv"
))

if (!is.na(diagnostics_file)) {
  readr::read_csv(diagnostics_file, show_col_types = FALSE) %>%
    mutate(across(where(is.numeric), ~ round(.x, 3))) %>%
    knitr::kable()
} else if (!is.na(full_model_path)) {
  draw_diagnostics <- posterior::summarise_draws(
    posterior::as_draws_df(model_full_brouwer_griffith),
    "rhat",
    "ess_bulk",
    "ess_tail"
  )

  sampler_diagnostics <- brms::nuts_params(model_full_brouwer_griffith)

  diagnostic_table <- tibble(
    model = basename(full_model_path),
    max_rhat = max(draw_diagnostics$rhat, na.rm = TRUE),
    min_bulk_ess = min(draw_diagnostics$ess_bulk, na.rm = TRUE),
    min_tail_ess = min(draw_diagnostics$ess_tail, na.rm = TRUE),
    divergent_transitions = sampler_diagnostics %>%
      filter(Parameter == "divergent__") %>%
      summarise(n = sum(Value == 1)) %>%
      pull(n),
    treedepth_hits = sampler_diagnostics %>%
      filter(Parameter == "treedepth__") %>%
      summarise(n = sum(Value >= 15)) %>%
      pull(n)
  )

  knitr::kable(diagnostic_table, digits = 3)
} else {
  cat("Multivariable moderator model diagnostics are not available yet.")
}
```
