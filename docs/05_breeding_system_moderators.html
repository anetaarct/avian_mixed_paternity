Model-based prevalence is summarised as the posterior mean on the probability scale, with 95% equal-tailed credible intervals. The inverse-logit transformation is applied to each posterior draw before averaging; all random effects are set to zero.

6.4 Model

This helper function documents the shared model structure used for all single-moderator models. These models are fitted outside this website workflow and saved as .rds files.

The BG breeding-system, BIRDBASE mating-system and parental-care models use 0 + category, with one logit coefficient per category and no shared population-level intercept. The binary cooperative-breeding model retains an intercept. Model-specific reference categories and priors are documented in the overall-model chapter.

Code 
fit_single_moderator <- function(formula, data) {
  brm(
    formula = formula,
    data = data,
    family = beta_binomial(link = "logit"),
    data2 = list(phylo_mat = phylo_mat),
    chains = 4,
    cores = 4,
    iter = 10000,
    warmup = 5000,
    control = list(
      adapt_delta = 0.99,
      max_treedepth = 15
    ),
    seed = 123
  )
}

6.5.4 Post-hoc pairwise contrasts

Pairwise contrasts are posterior means with 95% equal-tailed credible intervals. Each contrast compares the first category with the second. Log-odds differences are calculated within each posterior draw. Odds ratios are summarised after exponentiating each difference, so mean OR is the mean of the transformed draws, not the exponential of the mean log-odds difference.

Code
b <- brms::fixef(model_breeding_system_0, summary = FALSE)
pairs <- combn(colnames(b), 2L, simplify = FALSE)
breeding_system_contrasts <- do.call(rbind, lapply(pairs, function(pair) {
  difference <- b[, pair[1L]] - b[, pair[2L]]
  odds_ratio <- exp(difference)
  data.frame(
    contrast = paste(sub("breeding_system", "", pair, fixed = TRUE), collapse = " - "),
    estimate = mean(difference),
    lower.CrI = unname(quantile(difference, 0.025)),
    upper.CrI = unname(quantile(difference, 0.975)),
    OR = mean(odds_ratio),
    lower.OR = unname(quantile(odds_ratio, 0.025)),
    upper.OR = unname(quantile(odds_ratio, 0.975))
  )
}))

## Model

This helper function documents the shared model structure used for all single-moderator models. These models are fitted outside this website workflow and saved as `.rds` files.

The BG breeding-system, BIRDBASE mating-system and parental-care models use 0 + category, with one logit coefficient per category and no shared population-level intercept. The binary cooperative-breeding model retains an intercept. Model-specific reference categories and priors are documented in the [overall-model chapter](03_overall_model.qmd#model-coding-and-priors).

```{r}
#| label: single-moderator-helper
#| eval: false
#| echo: true

fit_single_moderator <- function(formula, data) {
  brm(
    formula = formula,
    data = data,
    family = beta_binomial(link = "logit"),
    data2 = list(phylo_mat = phylo_mat),
    chains = 4,
    cores = 4,
    iter = 10000,
    warmup = 5000,
    control = list(
      adapt_delta = 0.99,
      max_treedepth = 15
    ),
    seed = 123
  )
}
```

### Post-hoc pairwise contrasts

Pairwise contrasts are posterior means with 95% equal-tailed credible intervals. Each contrast compares the first category with the second. Log-odds differences are calculated within each posterior draw. Odds ratios are summarised after exponentiating each difference, so mean OR is the mean of the transformed draws, not the exponential of the mean log-odds difference.

```{r}
#| echo: true
#| code-fold: true
#| message: false
#| warning: false

b <- brms::fixef(model_breeding_system_0, summary = FALSE)
pairs <- combn(colnames(b), 2L, simplify = FALSE)
breeding_system_contrasts <- do.call(rbind, lapply(pairs, function(pair) {
  difference <- b[, pair[1L]] - b[, pair[2L]]
  odds_ratio <- exp(difference)
  data.frame(
    contrast = paste(sub("breeding_system", "", pair, fixed = TRUE), collapse = " - "),
    estimate = mean(difference),
    lower.CrI = unname(quantile(difference, 0.025)),
    upper.CrI = unname(quantile(difference, 0.975)),
    OR = mean(odds_ratio),
    lower.OR = unname(quantile(odds_ratio, 0.025)),
    upper.OR = unname(quantile(odds_ratio, 0.975))
  )
}))
knitr::kable(breeding_system_contrasts, digits = 3,
  caption = "Posterior means and 95% equal-tailed intervals: log-odds contrasts and odds ratios.")
```

```{r}
#| echo: false
```

```{r}
#| warning: false
b_cooperative <- brms::fixef(model_cooperative, summary = FALSE)
cooperative_probability_draws <- 100 * plogis(cbind(
  `Non-cooperative` = b_cooperative[, "Intercept"],
  Cooperative = b_cooperative[, "Intercept"] + b_cooperative[, "cooperative_breedingyes"]
))
cooperative_prevalence <- data.frame(
  `Cooperative breeding` = colnames(cooperative_probability_draws),
  `Posterior mean prevalence (%)` = colMeans(cooperative_probability_draws),
  `Lower 95% CrI` = apply(cooperative_probability_draws, 2, quantile, 0.025),
  `Upper 95% CrI` = apply(cooperative_probability_draws, 2, quantile, 0.975),
  row.names = NULL, check.names = FALSE
)
knitr::kable(cooperative_prevalence, digits = 2)
```

Posterior mean prevalence was 16.0% (95% equal-tailed CrI 1.0–57.0%) in non-cooperative species and 13.8% (0.8–52.0%) in cooperatively breeding species. Both estimates were highly uncertain. The posterior mean coefficient was −0.209 (95% equal-tailed CrI −0.716 to 0.304), and the posterior mean OR was 0.839 (0.489 to 1.355). OR is summarised as mean(exp(beta_draws)), whereas exp(mean(beta_draws)) = 0.812; the difference follows from nonlinear averaging.

## Heterogeneity summary

The table below compares residual heterogeneity across breeding-system, parental-care, and cooperative-breeding moderator models.

```{r}
#| echo: false
#| message: false
#| warning: false
variance_table <- readr::read_csv("tables/variance_audit/group_level_variances.csv", show_col_types = FALSE) |>
  dplyr::filter(Model %in% c("Overall model", "Breeding system", "Mono-/polygamy", "Parental care", "Cooperative breeding"))
knitr::kable(variance_table, digits = 3)
```

Group-level entries are posterior mean variances on the logit scale, calculated by squaring each posterior SD draw before averaging. Phi is the beta-binomial precision parameter. Models use different complete-case samples; these tables do not measure heterogeneity explained by individual moderators.
